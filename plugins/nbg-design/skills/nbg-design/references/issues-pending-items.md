### 2026-09-06 — Fixed: shadows rendered as solid gray blocks in macOS Preview (skill v1.19.0)
- Issue: In Preview (Quartz), the exported PDF showed the cover photo's shadow and the toolbar mock-ups' shadows on some pages as solid gray rectangles; other pages looked fine (their shadows were in fact missing); Chrome rendered every page correctly.
- Cause: Quartz clips Chrome's luminosity soft-mask forms to the page box in points but applies it in the form's 300-dpi device units — the top-left 24 % of the page. Masks entirely outside that corner are dropped and the fill is painted unmasked; masks across it are honoured only inside it.
- Solution: `scripts/lib/pdf-soft-masks.mjs` re-anchors each mask form to page space (`/Matrix`, prefixed `cm`, mapped BBox) as an incremental update; `export-pdf.mjs` applies it by default (`--keep-soft-masks` to skip), `fix-pdf-soft-masks.mjs` serves existing PDFs. The in-deck print path (block v13), whose file cannot be post-processed, prints blurred box-shadows as pre-rendered images behind their elements instead. Poppler renders before / after identically; Quartz now matches poppler. Verified by `test_scripts/pdf-soft-masks-roundtrip.mjs` and on the 38-page deck that raised the report. Details: `project-design.md` → "PDF soft masks re-anchored for macOS Preview".

### 2026-09-03 — Fixed three defects in `scripts/screenshot-deck.mjs` found while verifying the PDF export
- Detected: Reference screenshots of two real decks showed slide 1 for every slide, and the slide count was too high.
- Cause: (1) the navigation shim only toggled `.active`, so `.hidden`-toggle and stacked scrolling decks never changed slide; (2) the shim was injected at the first `</body>` string, which one deck had inside an HTML comment, so the shim never ran; (3) the slide counter matched `slide-title` / `slide-footer` as slides.
- Solution: The shim now isolates the Nth top-level `.slide` in place (hides the others with a class, lifts `.hidden` / `[hidden]` / inline display, keeps the deck's scaling), is injected before the last `</body>`, and the counter matches the exact class token. The browser locator moved to `scripts/lib/find-browser.mjs`.
- Verification: All three decks now capture 15 / 11 / 17 distinct slides and match the PDF pages.
